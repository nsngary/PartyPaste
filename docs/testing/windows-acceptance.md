# PartyPaste Windows 自用版驗收

狀態：尚未完成原生驗收。自動化瀏覽器測試與「程序可啟動」煙霧測試不能取代以下手動檢查。

這份清單用於未簽章的 Windows 10/11 自用版。每次換電腦、更新版本或準備分享前，複製一份 `release-candidate-template.md` 並填入實測結果。PartyPaste 只複製純文字，不模擬貼上、Enter 或遊戲輸入；獨佔全螢幕不支援，請改用無邊框或視窗模式。

## 測試環境與檔案

- [ ] 記錄 Windows 版本與 OS build（`winver`）。
- [ ] 記錄螢幕數量、排列、主螢幕與各螢幕縮放（100%／150%／200%）。
- [ ] 對照 `SHA256SUMS.txt` 驗證安裝版與可攜版 SHA-256。
- [ ] 確認檔名含 `unsigned-local`，並記錄 Windows 顯示的未簽章警告。
- [ ] 確認測試期間離線；此自用版不應發出更新請求。

## 安裝版生命週期（僅在專用測試環境）

- [ ] 以 current-user NSIS 安裝，不要求系統管理員權限。
- [ ] 首次啟動只有一個 PartyPaste 程序；再次啟動會聚焦既有視窗，不建立第二份程序。
- [ ] 系統匣可開啟管理器、顯示／隱藏浮動視窗及結束程式。
- [ ] 關閉管理器後程式仍在系統匣；由系統匣可重新開啟。
- [ ] 從舊版執行新版安裝程式後，語句、變數、設定與快捷鍵仍存在。
- [ ] 移除程式後確認是否保留使用者資料；只有在已有備份且明確需要時才手動刪除資料。

## 可攜版

- [ ] ZIP 解壓到新的空資料夾；根目錄含 `PartyPaste.exe`、`partypaste.portable`、`data/`、授權聲明與 build notice。
- [ ] 從一般可寫入路徑啟動，不需安裝且不要求系統管理員權限。
- [ ] 建立一筆測試語句後結束，再啟動仍可讀取；資料只出現在同資料夾的 `data/`。
- [ ] 整個資料夾複製到另一個可寫入路徑後仍可啟動並讀到資料。
- [ ] 匯出 JSON 備份後才刪除可攜版資料夾；刪除資料夾會永久刪除其本機資料。

## 視窗、DPI 與多螢幕

- [ ] 浮動視窗預設約 300×420，最小可縮至 240×160；另測 420 px 寬。
- [ ] 管理器預設約 1120×720，最小 760×560；無水平裁切且抽屜／編輯區可用。
- [ ] 在 100%、150%、200% 縮放下檢查字體、按鈕、焦點框、選單及捲動。
- [ ] 將兩個視窗分別移到不同 DPI 螢幕並重啟，尺寸和位置合理。
- [ ] 關閉程式後拔除次螢幕再啟動，兩個視窗都會回到可見工作區。
- [ ] 浮動視窗置頂切換只影響浮動視窗，不會讓管理器置頂。

## 日常核心流程

- [ ] 新增、修改、複製、刪除遊戲／群組／語句，並確認 10 秒復原。
- [ ] 用拖曳及「上移／下移／移至群組」完成排序。
- [ ] 在「小標題／完整語句」間切換；窄視窗仍能辨識並點擊。
- [ ] 新增、修改、排序、刪除遊戲範圍的變數及常用值。
- [ ] 模板缺值時不能複製；選取常用值及手動輸入後，預覽與剪貼簿文字完全相同。
- [ ] 預設介面為繁體中文；切換 English、重啟後仍為英文，再切回繁體中文。

## 快捷鍵與剪貼簿

- [ ] 自訂「顯示／隱藏浮動視窗」快捷鍵並重啟；新設定仍有效。
- [ ] 測試與 Windows／其他程式衝突的快捷鍵：顯示錯誤，原快捷鍵仍有效。
- [ ] 測試與語句快捷鍵互相衝突：拒絕儲存且不覆蓋原設定。
- [ ] 在記事本與一般文字輸入欄位貼上 Unicode、中文、空白與標點，結果完全一致。
- [ ] 在至少一款無邊框遊戲和一款視窗模式遊戲開啟對話欄後貼上；PartyPaste 本身不得送出訊息。
- [ ] 記錄代表性遊戲、模式與結果。獨佔全螢幕只記錄為不支援，不列為失敗。

## 備份與故障恢復

- [ ] 匯出 JSON，確認檔案位於使用者指定位置。
- [ ] 匯入有效備份時先顯示筆數預覽；確認後完整取代且自動建立安全備份。
- [ ] 匯入損壞／不相容 JSON 時，現有資料完全不變。
- [ ] 回復後檢查語句、排序、變數、常用值、語言與快捷鍵。
- [ ] 在離線狀態開啟設定頁；更新區只顯示手動更新說明，沒有檢查、下載或安裝動作。

## 通過標準

所有適用項目都要有 PASS 或附可重現問題。若剪貼簿、資料保存、視窗找回、單一程序、快捷鍵回復或備份取代任一失敗，不得標記為日用候選版。
